# Security Policy

This repository contains synthetic demos only. Do not include real customer data, credentials, tokens, cookies, or production logs in issues or pull requests.

## Reporting

Please use GitHub's private vulnerability reporting for this repository, or open a minimal issue without sensitive details.

## Scope

- Demo code and synthetic fixtures are in scope.
- Real customer systems, accounts, and data are out of scope.
- Face recognition / liveness is experimental and is not offered as a production capability.

## Data handling

- All public demos use synthetic data.
- No demo connects to a production ERP, bank, payment system, or real customer channel by default.
- Irreversible writes are disabled unless explicitly implemented and documented.
